Do you want to get one or multiple Qbeads?

Depending on who you are and what you want to do with them, there are three ways to get one. You are:
- **A User:** if you plan to use the Qbead to learn about quantum tech, stay updated for online or in-person workshops!
- **A Developer:** if you want to develop new experiments in the Qbead hardware, submit a pull request that is accepted in our GitHub and email us to set up a short meeting
- **An Educator:** if you want to use Qbeads to teach a class or workshop, submit a lecture or workshop plan via email and we will set up a short meeting 

Have fun!
